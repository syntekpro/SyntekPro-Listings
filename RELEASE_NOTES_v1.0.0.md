# SyntekPro Listings v1.0.0

Release date: 2026-06-04

## Highlights
- Complete listings platform for WordPress with broad listing-type support.
- Powerful search stack including map, radial, and drawn-area search.
- Full enquiry, viewing, CRM, import/export, and portal workflows.
- Builder support for Elementor and Divi.

## Included
- Core plugin bootstrap, CPTs, taxonomies, and meta boxes.
- 20+ shortcodes and frontend templates.
- Mortgage, stamp duty, rental yield, and affordability calculators.
- AI description tools, EPC generator, and QR code generator.
- Brochure, window card, and digital display outputs.
- White label, SEO compatibility, and i18n setup.
- Uninstall cleanup, readme, and language template.

## Notes
- Minimum requirements: WordPress 5.8+, PHP 7.4+.
- Plugin URL: https://plugins.syntekpro.com/listings
